  1. Install WebDesk Phone Host APK on your other Android phone (via USB adb install or the download button above).
  2. Open the app, paste the Server URL above, name the phone, and set an Access PIN.
  3. Tap Enable Accessibility Control (allows remote taps, swipes, Back/Home, & typing) — on Android 13+, open App Info → ⋮ → Allow restricted settings first if greyed out.
  4. Tap Start Mirror + Control Host and allow Screen Cast once — your phone appears online right here from anywhere!
